Media Inspector
===============

Using a release download:

Open the downloaded HTML file in your browser. If you downloaded the ZIP, extract it and open dist/index.html or dist/index.self-extract.html. Choose a video or audio file, or try the built-in WAV sample. Both variants work offline.

Windows quick start from a source checkout:

1. Double-click build-standalone.bat
2. Open dist\index.html (the build normally opens it automatically)
3. Choose a local video or audio file

The first build downloads and SHA-256 verifies the pinned FFmpeg WASM Builder v1.2.0 Media Inspector release. Runtime inspection is local-only and uses no server upload.
