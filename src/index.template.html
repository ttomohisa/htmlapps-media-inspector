使い方と注意事項



基本の使い方
  1. ファイルを選ぶと解析が始まります。「サンプルのWAVで試す」で3秒の音声を試せます。準備中もキャンセルできます。
  2. 「概要」で形式・長さと主な映像・音声の仕様を確認します。「トラック」では個々のストリームやカバー画像を確認できます。
  3. 「個人情報・保存」で日付などの候補を確認し、コピーを保存します。保存後に再検査で削除を確認した項目が表示されます。解析JSONは「詳細・出力」でコピー・保存できます。


長さはミリ秒単位で丸めて表示し、取得できない値は「—」になります。JSONの元の値は変更しません。コピーに失敗した場合は「JSONを保存」をお試しください。


概要の「技術情報の要約を保存」で、現在の解析結果のコンテナ・サイズ・長さ・ビットレートと全ストリームの技術情報をUTF-8テキストに保存できます。メタデータの値、チャプター名、再生可否の判定は含めません。コンテナは拡張子ではなく検出された形式を使い、曖昧な形式は併記します。保存ファイル名は元の名前に基づくため、共有前に氏名などが含まれていないか確認してください。JSONの内容は変わりません。


プライバシー
解析はこのHTML内のFFmpeg WebAssemblyで行います。選択したファイルや解析JSONをアプリ自身がサーバーへ送信することはありません。


メタデータ削除について
MP4 / MOV / M4V / M4A、MP3、FLAC、WAVは、映像・音声を再エンコードせずに撮影日時・位置情報・一般的な端末/ソフト情報タグ・タイトル・作者・コメントなどを取り除いた新しいコピーを保存できます。回転、HDR、色空間などの再生に必要な技術情報は保持します。チャプター、codec bitstream、専用Data / telemetry streamの中身は保持するため、そこに埋め込まれた名前・GPS・端末情報等は残る場合があります。


Media Doctorについて
ブラウザ再生の判定は参考情報です。OS・ブラウザ・ハードウェアによって対応状況が違うため、再生を保証するものではありません。


注意事項
  • コーデックのデコードは行わず、コンテナとストリームのヘッダー情報を中心に解析します。そのためファイルによって取得できない項目があります。
  • 一部の壊れたファイルや特殊な形式は解析できない場合があります。
  • 解析中は端末のメモリを使用します。大きなファイルでは処理できない場合があります。


解析・削除は途中でキャンセルできます。処理時間やメタデータ量が上限を超えた場合は保存せずに中断します。元ファイルは変更しません。拡張子が内容と違う場合は検出形式に合う名前で保存します。
