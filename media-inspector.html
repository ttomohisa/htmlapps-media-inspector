使い方と注意事項



基本の使い方
  1. 動画または音声ファイルを選びます。解析は自動で始まります。
  2. Media Doctorでブラウザ再生の注意点を確認し、Video / Audioカードで詳細を確認します。
  3. 「メタデータを削除」から個人情報を除いたコピーを保存できます。必要なら「詳細」から解析JSONもコピー・保存できます。


長さはミリ秒単位で丸めて表示し、取得できない値は「—」になります。JSONの元の値は変更しません。コピーに失敗した場合は「JSONを保存」をお試しください。コピー待ち中に解析結果を切り替えると、その結果への追加のコピー処理と通知は中止します。


基本情報の「技術情報の要約を保存」で、現在の解析結果のコンテナ・サイズ・長さ・ビットレートと全ストリームの技術情報をUTF-8テキストに保存できます。メタデータの値、チャプター名、再生可否の判定は含めません。コンテナは拡張子ではなく検出された形式を使い、曖昧な形式は併記します。保存ファイル名は元の名前に基づくため、共有前に氏名などが含まれていないか確認してください。JSONの内容は変わりません。


プライバシー
解析はこのHTML内のFFmpeg WebAssemblyで行います。選択したファイルや解析JSONをアプリ自身がサーバーへ送信することはありません。


メタデータ削除について
MP4 / MOV / M4V / M4A、MP3、FLAC、WAVは、映像・音声を再エンコードせずに撮影日時・位置情報・一般的な端末/ソフト情報タグ・タイトル・作者・コメントなどを取り除いた新しいコピーを保存できます。回転、HDR、色空間などの再生に必要な技術情報は保持します。チャプター、codec bitstream、専用Data / telemetry streamの中身は保持するため、そこに埋め込まれた名前・GPS・端末情報等は残る場合があります。


Media Doctorについて
ブラウザ再生判定は、ファイル情報、canPlayType()、端末上のネイティブ再生プローブを組み合わせた参考情報です。OS・ブラウザ・ハードウェアによって対応状況が違うため、絶対的な再生保証ではありません。


注意事項
  • コーデックのデコードは行わず、コンテナとストリームのヘッダー情報を中心に解析します。そのためファイルによって取得できない項目があります。
  • 一部の壊れたファイルや特殊な形式は解析できない場合があります。
  • 大きなファイルはWORKERFSで直接参照しますが、解析中はブラウザとFFmpeg WASMのメモリも使用します。
